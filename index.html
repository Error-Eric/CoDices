              workflow
              
写作即排版

              
左侧用纯 Markdown 记录模组，右侧实时编译为可折叠、可检索、可交叉跳转的交互式 H5。

            

            

              local-first
              
数据留在本机

              
草稿保存在浏览器 localStorage 中，不会上传到服务器。清除浏览器数据前请先导出 Markdown 或 H5。

            

            

              export
              
单文件交付

              
导出的 H5 自带样式、脚本、目录与索引导航，不依赖外部资源，适合直接分发给调查员或守密人。

            

            

              stack
              
技术栈

              
CodeMirror 6 提供源码编辑体验，markdown-it 负责解析，Vite 负责构建与静态部署。
